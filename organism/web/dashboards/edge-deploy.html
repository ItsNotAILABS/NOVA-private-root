II. Information-Theoretic Throughput

Claude Shannon proved in 1948 that every communication channel has a maximum capacity:

C = B × log₂(1 + S/N)

Where B = bandwidth in Hz, S/N = signal-to-noise ratio (linear). This is not an engineering approximation — it is a mathematical theorem. No coding scheme, no modulation, no compression can exceed it. It is the wall.

Example: WiFi 2.4 GHz with 20 MHz bandwidth and 30 dB SNR:

C = 20×10⁶ × log₂(1 + 10³) ≈ 199.3 Mbps

Real-world WiFi achieves ~65% of Shannon limit due to MAC overhead, retransmissions, and interference: approximately 129.5 Mbps effective.

  • Push notifications — receive server events even when app is closed

  • Frequency-aware routing — choose channel based on signal quality
