# Sonic Ninja Browser Intelligence — Public Release

Sonic Ninja is a local-first browser intelligence workspace powered by Vigil AI components. It helps users read, research, remember, organize, and stay aware while working in the browser.

## Product Promise

Sonic Ninja gives users a browser-side AI workspace with page summarization, page Q&A, highlights, memory, notes, research agents, knowledge graph workflows, safety awareness cues, and export tools.

## Public-Safe Claims

Approved:

- Local-first browser intelligence workspace.
- Browser side panel for reading, research, memory, and organization.
- Offline AI modes for summarization, classification, and question answering when local models are available.
- User-directed research agents and structured extraction workflows.
- Safety awareness features for phishing indicators, suspicious content, and PII awareness.

Not approved:

- Certified security product.
- Guaranteed protection from all cyber threats.
- Legal, financial, medical, or professional advice.
- Offensive cyber capabilities.
- Claims that every optional integration is fully local unless verified.

## Quick Start

1. Download or build the extension.
2. Load it unpacked in Chrome or Edge.
3. Open the side panel.
4. Summarize the current page.
5. Save highlights or notes.
6. Ask questions about what you are reading.
7. Run a research workflow.
8. Export the result.

## Release Boundary

This public release describes the user-facing browser product. Private NOVA, CAIN, and ORO governance protocols remain private. Public docs may reference a governed release process, but should not expose internal routes, private trunks, secrets, or unreleased capabilities.
