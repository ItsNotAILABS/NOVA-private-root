# Security Boundary

Sonic Ninja can provide security awareness features, but public documentation must not overclaim. It should be framed as an assistive browser awareness layer, not a certified security appliance.

## Allowed Public Language

- Helps identify suspicious content cues.
- Can surface phishing indicators.
- Can assist with PII awareness.
- Can support defensive review and safer browsing habits.
- Can help users organize security-relevant observations.

## Restricted Public Language

- Do not claim guaranteed protection from malware, phishing, fraud, or compromise.
- Do not claim certified security monitoring.
- Do not describe offensive cyber workflows.
- Do not provide exploit chains, persistence, evasion, credential theft, or unauthorized access instructions.

## CAIN Review Standard

Before publishing security-related claims, run a CAIN-style review:

1. Does the claim describe an assistive feature or a guarantee?
2. Does the claim imply certification?
3. Does the claim reveal private internals?
4. Does the claim invite offensive cyber usage?
5. Does the doc provide safe alternatives and user responsibility?

## Public Disclaimer

Sonic Ninja security awareness features are assistive. They do not replace antivirus, endpoint protection, enterprise SOC tooling, professional incident response, or user judgment.
