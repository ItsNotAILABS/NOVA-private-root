# Marketing Launch Copy — Sonic Ninja Browser Intelligence

## One-Line Positioning

Sonic Ninja is a local-first AI browser workspace for reading, researching, remembering, and organizing the web.

## Short Launch Copy

Meet Sonic Ninja: a browser-side AI workspace that helps you summarize pages, ask questions about what you are reading, save knowledge, run research workflows, and stay aware of suspicious content cues — all from one side panel.

## Founder Launch Post

I built Sonic Ninja because I wanted browser intelligence that felt like a workspace, not a chatbot tab. It brings reading, research, memory, notes, page Q&A, safety awareness, exports, and agent workflows into a local-first browser surface. This is the public product layer. Internally, it is governed by a stronger release process so features can move from experiment to real use without losing boundaries.

## Product Pillars

1. Read faster with page summaries.
2. Ask questions about current page content.
3. Save highlights, notes, and memories.
4. Build a searchable knowledge layer.
5. Run user-directed research agents.
6. Surface suspicious content cues.
7. Export useful reports.
8. Keep core workflows local-first where possible.
