# External Products Library (Projection Envelope)

Classification: `OPERATOR_INTERNAL`

Purpose:
- define what may be projected externally,
- enforce zero-exposure policy on all product surfaces,
- and bind projection contracts to constitutional gates and evidence.

This folder is for product projection contracts only.
It is not allowed to contain sovereign-private doctrine internals.

---

## 1) Projection rules

1. Every external artifact must map to a projection model (`P-MODEL-*`).
2. Every projection model must reference:
   - gate c evidence,
   - exposure audit,
   - rollback and incident control linkage.
3. External payloads must remain numeric/proof-safe unless explicitly reclassified.
