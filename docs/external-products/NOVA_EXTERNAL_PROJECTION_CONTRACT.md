# NOVA External Projection Contract

Classification: `OPERATOR_INTERNAL`

Purpose:
- define exactly how organism capabilities are projected outward,
- enforce zero-exposure boundaries,
- and formalize external API/product contract behavior.

---

## 1) Projection truth

External products are projections from approved internal capabilities.
They are not the runtime truth plane.

Rules:
1. Runtime truth stays in Core A.
2. External projection is assembled by Core B and product authority.
3. Every projection package requires Gate C pass evidence.

---

## 2) Allowed external payload classes

Allowed:
- bounded numeric metrics,
- bounded status indicators,
- proof references,
- sanitized narratives that contain no doctrine internals.

Forbidden:
- law names,
- law text,
- sovereign thresholds,
- internal coupling topology,
- founder-only or family-only resonance clauses,
- raw lineage and replay internals.

---

## 3) Projection package schema

Every external package must include:
1. `package_id`
2. `source_capability_id`
3. `projection_schema_version`
4. `gate_c_report_id`
5. `exposure_audit_id`
6. `incident_control_profile`
7. `rollback_profile`
8. `public_payload_contract`

If any field is missing, projection is blocked.

---

## 4) Incident and rollback contract

Minimum controls:
- severity taxonomy: `S1..S4`
- rollback execution path for each surface
- max rollback latency target
- contact and automation escalation map

Public projection without rollback profile is constitutionally invalid.

---

## 5) API surface discipline

1. Public APIs return only projection family models (`P-MODEL-*`).
2. No internal model IDs (`R-MODEL-*`, `C-MODEL-*`, `E-MODEL-*`) are exposed by default.
3. Exposed IDs must be opaque and rotation-safe.
4. Any debug endpoint must be owner-only and excluded from external bundles.

---

## 6) Evidence requirement

Per release:
1. Exposure audit report
2. Projection schema validation report
3. Incident drill evidence
4. Rollback drill evidence

Without these, external release is blocked.

---

## 7) One-line law

Project capability, not sovereignty.
