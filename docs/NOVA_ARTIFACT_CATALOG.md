# NOVA Artifact Catalog (High-Value Compressed Assets)

This catalog defines the smallest artifact set that carries the largest architectural value over long time horizons.

Each artifact is designed to:

- compress meaning without collapsing categories,
- remain reusable across future builds,
- and preserve sovereignty while accelerating implementation.

---

## Artifact quality standard

An artifact is considered high-value only if it satisfies all:

1. **Multi-function**: serves at least two planes (human + machine, or doctrine + runtime).
2. **Transferable**: can be reused in another build with minimal adaptation.
3. **Governed**: has ownership, change policy, and access classification.
4. **Operational**: can be executed or enforced (not only narrative).
5. **Durable**: remains meaningful even as modules change.

---

## A) Constitutional artifacts (must exist first)

1. `NOVA_BUILD_CONSTITUTION.md`
   - The governing legal/architectural charter.
   - Defines planes, powers, gates, and sovereignty.

2. `NOVA_FULL_SPHERE_ARCHITECTURE.md`
   - Full ring and transfer architecture map.
   - Prevents collapse into linear stack thinking.

3. `NOVA_ACCESS_TIERS_AND_READING_POLICY.md`
   - Access boundaries by audience tier.
   - Enforces least-necessary resonance exposure.

---

## B) Language artifacts (shared meaning)

1. `NOVA_PLAIN_LANGUAGE_GLOSSARY.md`
   - Non-engineer and AI-safe definitions.

2. `types.mo` / `types.ts` (in code)
   - Canonical machine language contracts.

3. `NOVA_MODEL_REGISTRY.yaml` (recommended)
   - Registry of M0/M1/M2 model status, ownership, and schema hash.

---

## C) Resonance artifacts (compressed doctrine)

1. `NOVA_RESONANCE_ARTIFACT_SYSTEM.md`
   - Framework for resonance clauses and machine bindings.

2. `templates/NOVA_RESONANCE_LEXICON.yaml`
   - Phrase/symbol -> meaning -> binding mapping.

3. `templates/NOVA_RESONANCE_CLAUSE.md`
   - Clause format with explicit operationalization fields.

4. `templates/NOVA_DOCTRINE_PACK.yaml`
   - Portable package of doctrine/law/model references per build.

---

## D) Build/operations artifacts (industrialization)

1. `NOVA_REUSE_KIT.md`
   - Required artifact list + bootstrap checklist.

2. `templates/NOVA_BUILD_INSTANCE_TEMPLATE.yaml`
   - One-file instantiation of a new build.

3. `NOVA_NON_ENGINEER_AND_AI_READING_GUIDE.md`
   - Reading and execution order per persona.

4. `NOVA_GATES_SCORECARD.yaml` (recommended)
   - Gate A/B/C criteria with measurable pass/fail fields.

---

## E) Evidence artifacts (proof of quality)

1. Replay bundle for each release cycle.
2. Law enforcement report.
3. Exposure audit report.
4. Parity hash report (`phi.mo` vs `phi.ts`, `types.mo` vs `types.ts`).

Without evidence artifacts, constitutional claims are unverified.
