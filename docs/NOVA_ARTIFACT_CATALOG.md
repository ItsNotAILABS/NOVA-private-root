# NOVA Artifact Catalog (High-Value Compressed Assets)

This catalog defines the smallest artifact set that carries the largest architectural value over long time horizons.

Each artifact is designed to:

- compress meaning without collapsing categories,
- remain reusable across future builds,
- and preserve sovereignty while accelerating implementation.

---

## Artifact quality standard

An artifact is considered high-value only if it satisfies all:

1. **Multi-function**: serves at least two planes (human + machine, or doctrine + runtime).
2. **Transferable**: can be reused in another build with minimal adaptation.
3. **Governed**: has ownership, change policy, and access classification.
4. **Operational**: can be executed or enforced (not only narrative).
5. **Durable**: remains meaningful even as modules change.
