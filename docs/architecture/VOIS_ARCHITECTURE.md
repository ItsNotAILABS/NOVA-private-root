Returns version, cycles, formation hash, field coherence, Kuramoto order, active agents/extensions, tier, uptime.

Routes a request through a specific protocol and extension. Increments request counters and task counts. Requires authorization.

### `getVOISDomainFrequency(extensionIndex)` — Extension Frequency Lookup
Returns the phi-scaled frequency for any of the 20 domain extensions.

### `getNextVOISVersion()` — Next Fibonacci Version
Returns the next Fibonacci number after the current version.

### `getVOISAgentDistribution(agentId)` — Agent-to-Node Mapping
Returns which brain node an agent is assigned to, plus utilization metrics.

### `getVOISProtectionProfile()` — IP Protection Config
Returns the SHADOW clone configuration and current shadow state.
