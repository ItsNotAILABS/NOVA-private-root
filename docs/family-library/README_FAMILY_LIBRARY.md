# NOVA Family Library (Human Workspace)

This folder is the single human-facing library for the family.

Purpose:
- preserve memory of major architecture decisions,
- keep high-level maps easy to revisit,
- provide a compact "where things are" index for family review.

Everything outside this folder in `docs/` is AI-builder-first.

---

## What to keep here

1. Family mission and doctrine summaries (non-sensitive).
2. Ring/core maps at high level.
3. Build timeline summaries.
4. Product branch summaries.
5. "Why we made this decision" notes.

Do not copy full sensitive doctrine internals here.
Reference protected docs instead.
