# Public-Safe Browser Intelligence Bridge

**Private source:** `ItsNotAILABS/NOVA-private-root`  
**Public target:** `FreddyCreates/potential-succotash`  
**Purpose:** connect the internal NOVA / CAIN / ORO governance layer to the public Sonic Ninja / Vigil AI browser intelligence product without leaking private internals.

## Bridge Principle

The bridge is a release boundary, not a code tunnel. The public repo receives install docs, product positioning, safe feature descriptions, privacy boundaries, security boundaries, roadmap, and public manifests. The private root keeps organism routing, internal gates, operator receipts, and protected roadmap material.

## Public-Safe Product Name

Use one clear public product name per launch surface. The current public repo uses **Sonic Ninja** and also references **Vigil AI**. The release package should state:

> Sonic Ninja is a local-first browser intelligence workspace powered by Vigil AI components.

This lets Sonic Ninja be the product, while Vigil AI remains the technical/organism layer.

## Public-Safe Claims

Approved language:

- Local-first browser intelligence workspace.
- Browser side panel for reading, research, memory, page Q&A, safety awareness, and exports.
- Offline AI modes for summarization, classification, and question answering when local model setup is available.
- Research agents for user-directed public web research and structured extraction.
- Security awareness features for phishing indicators, suspicious content cues, and PII awareness.
- Developer-friendly extension architecture with build and install commands.

Restricted language:

- No certification claims.
- No guarantee of total privacy across every optional integration.
- No legal, medical, financial, or security guarantees.
- No offensive cyber claims or instructions.
- No private NOVA root internals.
