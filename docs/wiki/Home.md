# NOVA Model Family Home

NOVA is organized as a family of specialized model contracts and runtime agents, not as a single vague chatbot. The family covers coding, tasking, creation, orchestration, talking/conversation, computation/proof, browser work, IDE work, governance, release management, and deployment preparation.

## Core family map

| ORIGO | executive routing and mission command | orchestrator | nova-origo-v1.0.0 |

## Operating doctrine

NOVA model-family releases must be proof-first. A model is not considered released because it has a name or prompt. A model is released when it has a card, scope, interfaces, boundaries, tests, receipts, and an integration lane.
