# Model Family Overview

The NOVA model family is a commercial operating family for building, coding, tasking, speaking, computing, evaluating, and releasing intelligent systems.

## Family layers

1. Foundation layer: memory, receipts, file vaults, manifests, audit logs, and identity.
2. Cognition layer: ORIGO, SENSUS, CORPUS, MATHESIS, VOX, CODEX, TASK, CREATIO, ORCHESTRA.
3. Runtime layer: Browser AI, NOVA IDE, App Factory, Command Runner Boundary, Deployment Planner.
4. Governance layer: quality gates, safety/compliance gates, permission boundaries, release manifests.
5. Product layer: apps, browser extensions, services, dashboards, agent tools, capsules, documentation, and deployment packages.

## Release standard

Every released model must have:

- a model card;
- a named purpose;
- input and output contracts;
- integration surfaces;
- safety and permission boundaries;
- acceptance tests;
- failure modes;
- receipt/audit behavior;
- release notes and semantic version.

## Commercial-grade meaning

Commercial-grade means the family can be operated by a user or company without relying on tribal knowledge. It must be documented, routable, testable, auditable, bounded, versioned, and recoverable.

## Non-claims

This release does not claim consciousness, autonomous legal agency, financial authorization, medical/legal advice authority, or silent production deployment. Those are outside the release boundary unless separately approved, tested, and governed.
