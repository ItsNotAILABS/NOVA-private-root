# Deep Research Papers: Research-Memory Surface

This note pins the visual and conceptual lane for the deep research papers created during the Medina runtime build sequence.

## Core idea

Research memory means the system preserves the chain from idea to build to test to receipt to paper to claim boundary to packet. The research paper is not separate from the runtime. It is the memory of what the runtime learned by building.

```text
idea -> build -> test -> receipt -> paper -> claim boundary -> packet -> memory
```
