## ANSWER: PATENT VS IP REGISTRATION

**Question:** What do you file first, the patent or the IP?

**Answer:** 

1. **Patent Application FIRST** — Under 35 U.S.C. § 102 (first-to-file), you must file before any public disclosure. File provisional applications immediately for all novel claims.

2. **Copyright Registration** — Can happen any time. Code is automatically copyrighted upon creation. Registration ($35-55) provides statutory damages.

3. **Trademark Registration** — File when brand names are finalized (FORMA, NeuroEmergence, Medina Tech).

4. **Trade Secret Protection** — Implement immediately. NDAs, access controls, confidentiality notices.
