# Enterprise Model Directory (Sovereign Families)

Classification: `BUILDER_CONFIDENTIAL`

Purpose:
- provide a permanent, reusable model family map,
- keep model ownership and consumers explicit,
- and prevent architectural collapse into ad hoc local payloads.

This directory is the canonical model taxonomy for enterprise orchestration.

---

This build uses **12 sovereign model families** as minimum complete enterprise set:

2. identity-authority
3. state-fabric
4. beat-time
5. coupling-transfer

---

## 2) Canonical machine map

Primary machine-readable index:
- `docs/model-directory/ENTERPRISE_MODEL_FAMILIES.yaml`

Supporting macro index:
- `docs/templates/NOVA_MODEL_DIRECTORY_INDEX.yaml`

---

## 3) Family folder contract

Each family folder should contain:
1. `README.md`
2. `MODELS.yaml`
3. owner and consumer map
4. gate touchpoints
5. exposure class bindings

This commit establishes the root structure and canonical YAML registry.
