- define the full N1 through N12 sovereign hierarchy as a nested organism map,

- prevent flat or linear collapse of the architecture.

---

## 1) Canonical hierarchy rule

The macro hierarchy is a rooted, nested sovereignty tree:

- N1 is the only root with no parent.
- Every N2..N12 node has an upstream lineage path to N1.
- Every node contains sub-model clusters that inherit law, frequency, and transfer constraints.
- Every outbound action from a node must have a replay path back to N1-rooted lineage.

No node is sovereign in isolation.
