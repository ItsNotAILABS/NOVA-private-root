# NOVA Build Constitution (Master Artifact)

Classification: `BUILDER_CONFIDENTIAL` (promote sections to `SOVEREIGN_PRIVATE` where needed)

This is the primary constitutional artifact for any NOVA/PARALLAX/SOVEREIGN build.
It is designed to be:

- compact enough to carry,
- strict enough to enforce,
- rich enough to transfer across generations.

---

## 1) Constitutional Purpose

Build and operate sovereign cognitive organisms that:

1. preserve doctrine and identity,
2. maintain no-drop continuity,
3. execute under law-gated arbitration,
4. project controlled external products without exposing sacred internals.

---

## 2) Constitutional Scope

This constitution governs:

- backend substrate,
- frontend substrate,
- canonical model language,
- runtime intelligence (Core A),
- intrinsic labs,
- workforce orchestration (Core B),
- product projection,
- swarm federation expansion.

If a component is not mapped to this constitution, it cannot be promoted to production.

---

## 3) Primary Axioms (A-series)

A1. Absolutes are discovered, not invented.  
A2. Doctrine constrains all execution.  
A3. Model language is canonical and shared.  
A4. Core A is final authority for runtime truth.  
A5. Core B is final authority for industrial execution proposals.  
A6. Intrinsic labs improve the organism from within.  
A7. Public projections must pass Zero-Exposure.  
A8. Every output becomes new input (loop never closes).  
A9. Every critical transition must be replayable.  
A10. Family inheritance of doctrine is mandatory.

---

## 4) Non-Collapse Rules (N-series)

N1. Absolute != Law  
N2. Law != Model  
N3. Model != Engine  
N4. Engine != Core  
N5. Core != Module  
N6. Intrinsic Lab != Industrial Workforce  
N7. Runtime Truth != Product Projection

Violation of any N-rule invalidates architecture review.

## 8) Model Constitution (M-series)

M0 Archetype: sovereign meaning and doctrine context.  
M1 Contract: typed schema and parity hash across backend/frontend.  
M2 Instance: runtime beat-level record.

A structure is not a constitutional model unless at least two independent systems consume it.

### Model family naming (forever naming standard)

Use these family names instead of generic "models":

- **Anchor Models (A-MODEL)**: Absolutes and encoded constants that anchor every build.
- **Constitution Models (C-MODEL)**: Law and doctrine control records.
- **Language Models (L-MODEL)**: Canonical typed contracts shared across systems.
- **Flow Models (F-MODEL)**: Orchestration and transfer route contracts.
- **Runtime Models (R-MODEL)**: Live beat-level organism state instances.
- **Lab Models (X-MODEL)**: Intrinsic self-improvement state and experiment records.
- **Workforce Models (W-MODEL)**: Build/release industrial orchestration records.
- **Projection Models (P-MODEL)**: External product and API-safe projection records.
- **Evidence Models (E-MODEL)**: Replay, proof, audit, and parity evidence records.
