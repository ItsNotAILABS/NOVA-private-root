## Recommended Release Order

### Wave 1 (immediate): Papers 1, 4, 5

- **Paper 1** establishes the intellectual foundation (Module Product Theory,
  Inverse Architecture Law) that all subsequent papers cite.
- **Paper 4** is the most novel contribution: the Paper–Engine Isomorphism.
  It requires no prior knowledge of NOVA and speaks directly to the CS
  theory and programming languages communities.
- **Paper 5** targets the AI/organisational science intersection.
  It is self-contained and accessible to a broad audience.

### Wave 2 (hold briefly): Papers 2, 3

- **Paper 2** requires the 2026 Frontiers in Human Neuroscience citation to
  be confirmed and linked before submission.  Also worth adding a figure
  showing the φ-ladder and the 12-node frequency table.
- **Paper 3** should be extended with a formal complexity analysis
  (Section 7) and a latency benchmark from the live NOVA deployment before
  submission to a systems venue.
