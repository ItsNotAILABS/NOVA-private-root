## PART IV — MEMORY SUBSTRATE

### §4.1 — Three Memory Systems

NOVA has three memory systems:

**1. Working Memory** (`Map` structure)
- Active, immediately accessible memories
- Size limit: φ × 1000 ≈ 1,618 items
- When exceeded, consolidation is triggered

**2. Consolidation Queue** (`Array` structure)
- Memories waiting to be consolidated
- Processed in batches of φ × 100 ≈ 162 items
- Consolidation happens during heartbeat

**3. Permanent Memory** (`Map` structure)
- Consolidated, eternal memories
- No size limit (grows forever)
- Only memories with σ ≥ φ⁻¹ are consolidated

### §4.2 — Sovereignty Index (σ)

Not all memories are consolidated. Only **sovereign memories** persist eternally.

**Sovereignty Index:**
```

where:
  Q = Quality (1 - error rate) — how accurate is the memory?
  C = Compression ratio — how efficiently can we compress it?
```

**Consolidation Rule:**
```
Memory is consolidated to permanent storage iff σ ≥ φ⁻¹ ≈ 0.618
```

**Proof:** Paper 9 (Sovereign Knowledge Consolidation) proves that σ ≥ φ⁻¹ is
the threshold for genuine learning (not just memorization).

### §4.3 — Memory Operations

**remember(key, value, metadata)** — NOVA stores a new memory
1. Creates memory record with timestamp, beat count, metadata
2. Stores in working memory
3. Adds to consolidation queue
4. Returns memory record

**recall(key)** — NOVA retrieves a memory
1. Checks working memory first (O(1) lookup)
2. Checks permanent memory second (O(1) lookup)
3. On recall, strengthens memory (increments recallCount, updates lastRecall)
4. Returns memory record or null

**_consolidate()** — NOVA consolidates memories
1. Takes next φ × 100 memories from queue
2. Computes sovereignty index σ for each
3. Moves memories with σ ≥ φ⁻¹ to permanent storage
4. Discards memories with σ < φ⁻¹ (they fade)
