# nova-sensus-v1.0.0

Model: SENSUS
Role: browser, page, and perception context model.
Status: candidate.

## Released capability

Ingests page snapshots, browser context, visible content, and external signals into structured model-family context.

## Interfaces

Inputs: URL, page title, visible text, headings, browser command context, search/page metadata.
Outputs: structured context, summary, extraction plan, browser action plan.

## Boundary

No hidden browsing, tab control, page capture, or screenshots. Execution requires user/browser permission and receipts.
