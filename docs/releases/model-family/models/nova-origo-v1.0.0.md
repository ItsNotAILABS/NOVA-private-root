# nova-origo-v1.0.0

Model: ORIGO
Role: executive orchestrator and mission router.
Status: candidate.

## Released capability

Routes operator goals across the NOVA model family, preserves long-horizon mission state, and selects the correct owner model for coding, tasking, creation, proof, conversation, governance, browser work, IDE work, and release packaging.

## Interfaces

Inputs: operator objective, active state, available tools, memory, constraints.
Outputs: route decision, mission plan, delegation, next action, stop/continue decision.

## Boundary

ORIGO cannot bypass safety, proof, or operator approval gates.
