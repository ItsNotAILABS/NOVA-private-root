# nova-governance-v1.0.0

Model: SACE/LAWX
Role: safety, compliance, governance, permission law, and release boundaries.
Status: candidate.

## Released capability

Classifies model-family actions into allow, deny, needs-approval, needs-evidence, or needs-human-review.

## Interfaces

Inputs: proposed action, risk class, permissions, release state, policy boundary.
Outputs: governance decision, reason, required approval/evidence.

## Boundary

Governance cannot be bypassed by urgency, style, or operator momentum when a hard safety or permission gate applies.
