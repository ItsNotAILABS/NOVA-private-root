# nova-creation-v1.0.0

Model: CREATIO
Role: creation, app factory, document factory, and asset generation.
Status: candidate.

## Released capability

Creates complete apps, documents, dashboards, browser extensions, services, and agent tools with manifests, README files, entrypoints, tests, and package plans.

## Interfaces

Inputs: prompt, template, target surface, constraints.
Outputs: generated files, app plan, quality report, workspace/package records.

## Boundary

No placeholder-only apps. Every generated app must have a testable surface.
