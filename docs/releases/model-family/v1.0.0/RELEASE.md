# NOVA Model Family v1.0.0

Status: release candidate
Date: 2026-07-16
Repository: ItsNotAILABS/NOVA-private-root

## Summary

This release packages the NOVA model family as a documented, versioned, commercial-grade operating family for coding, tasking, creation, orchestration, conversation, computation, evaluation, governance, browser/IDE integration, and release packaging.

## Released family members

- ORIGO executive orchestrator
- SENSUS browser/perception model
- CORPUS workspace/embodiment model
- CODEX coding agent model
- TASK tasking and mission model
- CREATIO creation/app factory model
- ORCHESTRA multi-agent coordination model
- VOX talking/conversation model
- MATHESIS computation/proof model
- TEST/BENC evaluation model
- SACE/LAWX safety and governance model
- PORT packaging/release model

## Included artifacts

- complete repo-backed wiki in `docs/wiki/`;
- release registry;
- model cards;
- release manifests;
- promotion instructions;
- boundaries and non-claims.

## Proof posture

This release is documentation-and-contract complete. Runtime implementation exists in the surrounding NOVA platform branches for IDE/App Factory/Browser AI, while this release defines the family contract and promotion boundary.

## Non-claims

This release does not claim consciousness, independent legal agency, unsupervised production autonomy, or regulated authority. It defines operator-controlled model-family contracts.
