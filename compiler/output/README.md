# Compiler Output

This directory contains compiled artifacts from the Universal Compiler.

All output files are generated during compilation and should not be committed to version control.

## Output Files

- `nova-unified.wasm` — Unified WASM module
- `nova-unified` — Native executable
- `nova-unified.map` — Symbol map
- `*.ir` — Intermediate representations
- `*.log` — Compilation logs

## .gitignore

All files in this directory are ignored by git (see `.gitignore`).
